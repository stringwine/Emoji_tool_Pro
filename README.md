# Emoji Tool Pro

Emoji Tool Pro 是一款用于 **Blender 中 MMD 角色表情动画**的插件。选好情绪、拖动强度，就能在角色上实时预览眉毛、眼睛和嘴巴的组合效果，再把结果写入 Morph 关键帧。

## 功能

- **18 种情绪预设**。每种预设有 20%、50%、100% 三个强度锚点，滑块可在锚点之间连续调整。
- **表情叠加与替换**。可分别控制眉毛、眼睛和嘴巴，也可以微调单个 Morph。默认叠加模式支持在已有表情上继续调整。
- **MMD Placeholder 支持**。可通过已绑定的 Placeholder 实时预览和打帧。
- **关键帧状态显示**。情绪按钮用菱形标记当前帧或其他帧的打帧状态。强度栏会显示已记录的情绪名称和百分比，0% 也可以打帧。
- **中文 Morph 分类与漫画特效**。形态键按区域分类，常见日文 Morph 有中文译名，可切换查看原名。脸红、星星眼等特效可单独预览和打帧。
- **自动眨眼与音频转口型**。支持单次眨眼、自动眨眼和从音频生成口型。情绪操作默认保护眨眼和口型通道。
- **自定义预设与映射**。可通过 JSON 导入和导出角色的 Morph 映射及情绪预设。

## 下载与安装

1. 前往 [GitHub Releases](https://github.com/stringwine/Emoji_tool_Pro/releases)，下载 `MMD_Emoji_tool_Pro_3.4.8.zip`。
2. 在 Blender 中打开 **编辑 → 偏好设置 → 插件**，选择 **安装** 或 **从磁盘安装**，直接选中 ZIP 并启用插件。
3. 回到 3D 视图，选中 MMD 角色或其面部网格，按 `N` 打开侧栏，在 **MMD表情** 标签中找到 **MMD Emotion Studio**。

如果已安装旧版 Pro，先停用并移除旧版再安装。如果同时装有 `Pro_turbo`，请保持它停用，两者共用部分 Blender 注册名称。

## 快速上手

1. 点选一个情绪，例如「开心」，拖动强度滑块预览效果。
2. 在起始帧把强度设为 **0%**，点 **当前帧 K 帧**。
3. 移到目标帧，把强度拉到 **70%**，再点一次 **当前帧 K 帧**。Blender 会在两帧之间插值。
4. 拖动时间轴查看效果。情绪按钮上的实心菱形表示该情绪在当前帧有关键帧，空心菱形表示它在其他帧打过关键帧。

## 测试环境

3.4.8 在 Windows 上使用 Goo Engine 4.1.1 和合成 Placeholder 验证了实时预览、Morph 打帧和切帧状态。音频转口型使用安装包内附的 Windows 版 FFmpeg。插件将表情写入 Shape Key 曲线，可供 MMD Tools 的 VMD 导出流程读取。真实 PMX 模型的 VMD 导出和回放尚未做端到端验证。
